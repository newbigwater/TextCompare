# 데이터 흐름

[[00-개요|← 개요로 돌아가기]]

## 비교 실행 흐름 (파일 로드 → 화면 렌더링)

```mermaid
flowchart TD
    A["FilePickerControl: 비교 클릭 / 드래그앤드롭"] --> B["MainForm.OnCompareRequested"]
    B --> C{"확장자 둘 다<br/>.xml / .json ?"}
    C -- "예 (XML)" --> D1["XmlStructureParser.ParseFile"]
    C -- "예 (JSON)" --> D2["EncodingDetector.ReadAllText<br/>+ JsonStructureParser.Parse"]
    C -- "아니오" --> D3["EncodingDetector.ReadAllText<br/>+ LineSplitter.Split"]
    D1 --> E1["StructureDiffer.Diff<br/>(XmlPrettyPrinter)"]
    D2 --> E2["StructureDiffer.Diff<br/>(JsonPrettyPrinter)"]
    D3 --> E3["DiffDocument.Build<br/>= MyersDiff&lt;string&gt; + DocumentAligner"]
    E1 --> F["List&lt;AlignedRow&gt;"]
    E2 --> F
    E3 --> F
    F --> G["DiffDocument.FromRows"]
    G --> H["DiffViewerControl.SetDocument"]
    G --> I["LocationPaneControl.Document"]
    H --> J["DiffPaneControl.OnPaint<br/>(owner-drawn, 가상 스크롤)"]
```

- XML/JSON 구조 비교와 라인 비교는 **`List<AlignedRow>`를 만드는 지점까지만 다르고, 그 이후(`DiffDocument.FromRows`부터)는 완전히 동일한 경로**를 지난다.
- 인코딩: XML은 `XDocument.Load`가 XML 선언을 직접 신뢰(가장 신뢰도 높음). 그 외(JSON/텍스트)는 `EncodingDetector`가 BOM → UTF-8 엄격 검증 → CP949(EUC-KR) 순으로 판별.

## 편집 모드 재비교 흐름

```mermaid
flowchart TD
    A["사용자가 RichTextBox에 타이핑"] --> B["OnEditorTextChanged"]
    B --> C["디바운스 Timer 재시작 (600ms)"]
    C -- "600ms 동안 추가 입력 없음" --> D["RediffFromEditors"]
    D --> E["LineSplitter.Split(좌/우 텍스트)"]
    E --> F["DiffDocument.Build (재비교)"]
    F --> G["DiffHighlighter.ApplyRowColors<br/>(줄 배경 + 문자 단위 강조)"]
    G --> H["ContentEdited 이벤트"]
    H --> I["MainForm: '수정됨' 상태 갱신, 차이 개수 갱신"]
```

편집 모드는 XML/JSON 구조 비교를 지원하지 않으므로, 이 경로는 항상 라인 비교(`DiffDocument.Build`)만 사용한다.

## 저장 흐름

`Ctrl+S` → `MainForm.SaveChanges()` → 파일 로드 시 저장해둔 `_leftEncoding`/`_rightEncoding`으로 `File.WriteAllText(path, DiffViewerControl.LeftEditorText/RightEditorText, encoding)`. ghost 행이 저장 텍스트에 섞이지 않는 이유는 [[04-UI-레이어#편집-모드]] 참고.
