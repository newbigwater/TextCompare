# 외부 라이브러리

[[00-개요|← 개요로 돌아가기]]

## 요약

TextCompare는 **NuGet 패키지를 전혀 사용하지 않는다.** `packages.config`/`.nuspec`이 프로젝트에 존재하지 않으며, `TextCompare.csproj`의 `<Reference>` 항목은 모두 **.NET Framework 4.8에 기본 내장된 어셈블리(GAC/Framework 참조)**다. Myers diff, JSON 파서, XML pretty-printer 등 비교 로직은 전부 이 프로젝트 안에서 직접 구현했다([[02-핵심-비교-알고리즘]], [[03-구조적-비교-XML-JSON]] 참고) — 외부 diff 라이브러리나 JSON 라이브러리(Newtonsoft.Json 등)에 의존하지 않는다.

## 실제로 사용 중인 참조

| 어셈블리 | 용도 | 주요 사용처 |
|---|---|---|
| `System.Windows.Forms` | 전체 UI 프레임워크(Form, UserControl, 컨트롤, 이벤트) | `TextCompare.Controls`, `TextCompare.Builders`, `MainForm` 전역 |
| `System.Drawing` | GDI+ owner-drawing(`DiffPaneControl`/`LocationPaneControl`의 `OnPaint`), `Font`/`Color`/`Point` 등 | `Controls/DiffPaneControl.cs`, `Controls/LocationPaneControl.cs` 등 |
| `System.Xml.Linq` | `XDocument`/`XElement`/`XAttribute`로 XML 파싱 | `Structure/XmlStructureParser.cs` |
| `System.Xml` | `System.Xml.Linq`의 의존 어셈블리 | (`System.Xml.Linq` 경유 간접 사용) |
| `System.Core` | LINQ(`System.Linq`), `HashSet<T>` 등 | `Controls/FilePickerControl.cs`, `Structure/XmlStructureParser.cs`, `Structure/NodeKeyStrategy.cs` 등 |
| `System` | BCL 기본(컬렉션, IO, 텍스트, 예외 등) | 프로젝트 전역 |

## csproj에는 있지만 실제로 사용하지 않는 참조

Visual Studio가 WinForms 프로젝트 생성 시 기본으로 추가하는 템플릿 참조로, 코드에서 실제로 쓰인 곳은 없다(grep 기준: `.resx`/`.csproj` 자체 외에는 매치 없음). 향후 정리 시 제거해도 무방하다:

- `System.Data`, `System.Data.DataSetExtensions`
- `System.Deployment`
- `System.Net.Http`
- `Microsoft.CSharp`

## 참고 자료(코드로 포함되지 않음)

- `03. Src/winmerge/` — [WinMerge](https://manual.winmerge.org/en/) 소스 코드. 참고용으로만 보관되며, TextCompare 빌드에는 포함되지 않는다(별도 프로젝트/솔루션).
